Company System Using MVC
A comprehensive Company Management System built with ASP.NET Core MVC and .NET framework for managing employees, departments, and organizational structure.
Key Features:

Complete CRUD operations for Departments and Employees with image upload support
Generic Repository and Unit of Work patterns for efficient data management
Advanced search functionality and AutoMapper integration for seamless object mapping
Full Authentication system including SignUp, SignIn, SignOut, ForgetPassword, and ResetPassword
User and Role management with complete CRUD operations and role-based access control
Employee-Department relationship management with proper database design
Responsive UI with client/server-side validation and secure file upload capabilities

Technologies: ASP.NET Core MVC, Entity Framework, Generic Repository Pattern, Unit of Work, AutoMapper, Identity Framework, Role-Based Authorization.
